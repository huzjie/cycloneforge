# 架构总览

cycloneforge 由四层组成，数据从下往上流动：

```
数据层 data/    合成台风（Holland 风场 + 台风动力学）-> 特征/目标样本
模型层 nn+model 编码器 -> 共享主干 MLP -> 三要素预测头（轨迹/强度/风场）
预测层 forecast 滚动自回归 + 涡旋定位 + 提前量 + 集合预报
评估层 eval     轨迹/强度/风场误差 + CRPS + 技能评分 + 基准
```

## 设计原则

1. **零依赖内核**：张量、反向传播、图结构、球面几何全部标准库实现，克隆即跑。
2. **确定性可复现**：`seed_from` 从字符串派生确定性 RNG，两次运行逐位一致。
3. **三头共享主干**：轨迹/强度/风场共享编码器，梯度反向约束统一物理表示。
4. **可插拔**：合成数据与真实数据（NetCDF）走同一 `make_dataset` 接口。

## 关键模块

- `nn/autodiff.py`：标量自动微分引擎（micrograd 风格），理解反向传播的最小原型
- `grid/icosphere.py`：二十面体递归细分，近均匀球面网格
- `forecast/rollout.py`：滚动自回归，上一步预测写回为下一步输入
- `eval/crs.py`：集合预报 CRPS 评分
